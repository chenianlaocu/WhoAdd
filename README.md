# WhoAdd - 首拉通报与开怪快照

WhoAdd 是一个面向 WoW 时光服 `_classic_titan_` 客户端的团队开怪记录插件（Interface `38001`）。插件会识别首次引怪，通报开怪者，并在引怪瞬间保存团队快照。

原版插件 WhoAdd 首拉原版作者：**甜甜哥不口胡-时光VI**  
增强版作者：**陳年老醋-时光VI <肯瑞托>公会**

## 功能

- 支持“通报所有”“仅通报团队 Boss”“不通报”三种通报范围。
- 支持自定义文字通报模板，以及文字通报、弹窗通报、声音提醒独立开关。
- 默认提示音使用 `SOUNDKIT.IG_MAINMENU_OPEN`。
- 支持脱战后延迟通报；弹窗与声音仍在确认开怪时立即触发。
- 通报可附加开怪者与怪物之间的距离。
- 三标签页面板：开怪记录、设置、Boss 资料库。
- 点击任意历史记录可查看对应开怪快照。
- 快照记录全团每位玩家的位置、施法或引导、当前目标、血量百分比、与怪物距离和角色职责。
- 引怪记录持久化到 `WhoAddDB`，保留最近 3 天并自动清理；设置修改后即时保存。
- 支持 LibDBIcon 小地图图片图标，左键打开记录，右键打开设置。
- 内置首领数据覆盖熔火之心、祖尔格拉布、毒蛇神殿、风暴要塞、纳克萨玛斯、黑曜石圣殿、永恒之眼、阿尔卡冯的宝库、十字军的试炼、奥杜尔、太阳井高地和祖阿曼等副本。

## 开怪检测

WhoAdd 同时使用战斗日志、团队目标、NPC 交互和遭遇战事件进行交叉确认：

- Boss、关联小怪或首领召唤物首次进入战斗时会归入对应首领，同一场战斗不重复提示开怪。
- NPC 对话开怪会记录所有点击或选中相关 NPC 的团队成员，包括先后顺序、点击时刻和持续时间；Boss 开怪后合并为一条消息通报并清空候选名单。
- 十字军的试炼使用 NPC `34816` 巴雷特·拉姆瑟进行对话开怪检测；锋鳞使用远征军指挥官 `33210`。
- 尤格-萨隆参考先进战斗记录思路，以遭遇战或战斗开始信号作为主要判定；萨拉不要求点击或选中，守护者和阶段小怪不作为开怪依据。
- 基尔加丹之手等首领关联小怪会被归入对应 Boss，并参与“仅通报团队 Boss”判定。
- 阵营冠军等多目标场景只通报第一个有效开怪目标，避免刷屏。
- 猎人印记、袋里藏沙、TOC 雪地狗头人 `34800`、火焰炸弹 `34854`、金度的祭品巨魔 `14826` 等干扰项不会触发开怪记录。

## 安装

1. 下载 Release 中的 `WhoAdd-4.6.5.zip` 并解压。
2. 将 `WhoAdd` 文件夹放入：

   ```text
   World of Warcraft\_classic_titan_\Interface\AddOns\WhoAdd
   ```

3. `WhoAdd.toc` 必须直接位于 `WhoAdd` 文件夹内。
4. 进入游戏或执行 `/reload`，然后输入 `/wadd`。

## 命令

| 命令 | 功能 |
| --- | --- |
| `/wadd` | 打开主面板 |
| `/wadd close` | 关闭主面板 |
| `/wadd settings` | 打开设置页 |
| `/wadd bosses` | 查看 Boss 资料库 |
| `/wadd all` | 通报所有开怪 |
| `/wadd boss` | 仅通报团队 Boss |
| `/wadd none` | 关闭通报 |
| `/wadd save` | 立即保存设置 |
| `/wadd reset` | 清空开怪记录 |
| `/wadd test` | 测试弹窗与声音 |
| `/wadd debug` | 切换调试输出 |

## 通报模板

默认模板：

```text
[首拉] {puller} {type} {mob}{distance}
```

可用占位符：

- `{puller}`：开怪者
- `{mob}`：开怪目标
- `{type}`：动作或开怪类型
- `{distance}`：与怪物距离
- `{boss}`：所属首领
- `{raid}`：副本名称
- `{time}`：时间
- `{source}`：检测来源
- `{npcid}`：NPC ID
- `{count}`：团队人数
- `{npc}`：NPC 点击者信息

## 数据保存

记录与设置保存在账号 SavedVariables 的 `WhoAddDB` 中。开怪历史保留 3 天，过期记录会自动删除；修改面板设置会立即写入存档。
